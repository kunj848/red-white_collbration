================================================================================
     INSTAGRAM ACCOUNT MANAGER - DICTIONARY SAVE LOGIC & WORKING CODE
================================================================================

This document explains the complete logic, flow, and Python code used to
save user credentials into the dictionary while enforcing duplicate key protection.

--------------------------------------------------------------------------------
1. DATA STRUCTURE DEFINITION
--------------------------------------------------------------------------------
The application stores user credentials inside an in-memory Python dictionary:

    self.user_database = {}

Format:
    { "username": "password" }

Where:
    - Key   = Unique Instagram username (String)
    - Value = User's password (String)


--------------------------------------------------------------------------------
2. STEP-BY-STEP SAVE PROCESS (How Data is Saved)
--------------------------------------------------------------------------------
When the user clicks the "Create Account" button, the function `create_account()`
executes in four distinct steps:

[Step 1] Retrieve and Clean Inputs:
    username = self.reg_user_var.get().strip()
    password = self.reg_pass_var.get().strip()

    - `.get()` gets the text typed by the user.
    - `.strip()` removes accidental whitespace at beginning or end.

[Step 2] Validate Non-Empty Inputs:
    if not username or not password:
        messagebox.showwarning("Input Missing", "Username and password cannot be empty.")
        return

    - Ensures both username and password have actual characters.

[Step 3] DUPLICATE KEY CHECK (Core Requirement):
    if username in self.user_database:
        # Key already exists in the dictionary!
        messagebox.showerror(
            "Duplicate Username Error",
            f"The username '{username}' is already taken!\n\n"
            f"In Python dictionaries, keys must be unique.\n"
            f"Please choose a different username."
        )
        return

    - Python dictionaries DO NOT allow duplicate keys.
    - If you don't check `username in self.user_database`, Python will silently
      OVERWRITE the previous user's password.
    - This check stops execution immediately and alerts the user.

[Step 4] Save into Dictionary:
    self.user_database[username] = password

    - Inserts the new key-value pair into the dictionary.
    - Example result:
      user_database = {
          "kunjbosamiya": "kunj@10122003"
      }

[Step 5] Feedback & UI Refresh:
    messagebox.showinfo("Account Created", f"Success! Account for @{username} has been registered.")
    self.reg_user_var.set("")    # Clears username input box
    self.reg_pass_var.set("")    # Clears password input box
    self._refresh_ui()           # Updates live table & raw dict display


--------------------------------------------------------------------------------
3. COMPLETE PYTHON FUNCTION CODE (From app.py)
--------------------------------------------------------------------------------

def create_account(self):
    username = self.reg_user_var.get().strip()
    password = self.reg_pass_var.get().strip()

    # 1. Validation for empty input
    if not username or not password:
        self.reg_banner.config(
            text="⚠️ Please enter both username and password!",
            fg="#FFAA00",
            bg="#261E10"
        )
        messagebox.showwarning("Input Missing", "Username and password cannot be empty.")
        return

    # 2. Check for Duplicate Key in Dictionary
    if username in self.user_database:
        err_msg = f"❌ Error: Username '{username}' already exists!\nDuplicate keys are not allowed in Python dictionaries."
        self.reg_banner.config(
            text=err_msg,
            fg=self.error_color,
            bg="#2A1018"
        )
        messagebox.showerror(
            "Duplicate Username Error",
            f"The username '{username}' is already taken!\n\n"
            f"In Python dictionaries, keys must be unique.\n"
            f"Please choose a different username."
        )
        return

    # 3. Store username as Key and password as Value
    self.user_database[username] = password

    # 4. Display Success
    success_msg = f"✅ Account successfully created for @{username}!\nStored as key '{username}' in user dictionary."
    self.reg_banner.config(
        text=success_msg,
        fg=self.success_color,
        bg="#0E2319"
    )
    messagebox.showinfo(
        "Account Created",
        f"Success! Account for @{username} has been registered."
    )

    # 5. Clear fields and refresh table
    self.reg_user_var.set("")
    self.reg_pass_var.set("")
    self._refresh_ui()


--------------------------------------------------------------------------------
4. HOW THE SAVED DATA IS DISPLAYED & VERIFIED
--------------------------------------------------------------------------------
In the `_refresh_ui()` method:

1. Accounts Table (Treeview):
   Iterates through the saved dictionary:
       for u, p in self.user_database.items():
           masked = "•" * len(p)
           self.tree.insert("", tk.END, values=(f"@{u}", f"{masked} ({p})"))

2. Raw Python Dictionary Text Box:
   Shows the exact dictionary data structure:
       self.dict_text.insert("1.0", repr(self.user_database))
   Output example:
       {'kunjbosamiya': 'kunj@10122003'}

3. Counter:
       count = len(self.user_database)
       self.status_label.config(text=f"Ready. {count} accounts stored in dictionary.")


--------------------------------------------------------------------------------
5. OPTIONAL: SAVING TO A PERMANENT JSON/TEXT FILE (PERSISTENCE)
--------------------------------------------------------------------------------
If you also want to save the dictionary permanently to a local file on your hard drive,
you can use Python's built-in `json` module:

import json

# To save dictionary to file:
def save_to_file(user_dict, filename="users_database.json"):
    with open(filename, "w") as f:
        json.dump(user_dict, f, indent=4)
    print("Database saved successfully!")

# To load dictionary from file:
def load_from_file(filename="users_database.json"):
    try:
        with open(filename, "r") as f:
            return json.load(f)
    except FileNotFoundError:
        return {}
